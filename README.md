# Projetos Python com APIs

Este repositório reúne três projetos desenvolvidos em **Python**, com foco em consumo de APIs, análise de dados, visualização de informações e criação de interfaces gráficas.

Os projetos exploram conceitos como requisições HTTP, tratamento de dados JSON, integração com APIs externas, análise de sentimentos, geração de gráficos e desenvolvimento de interfaces com Tkinter.

## Tecnologias utilizadas

* Python
* Tkinter
* Requests
* Pandas
* Matplotlib
* TextBlob
* Pyttsx3
* APIs externas

---

## 🎙️ Conversor de Texto em Voz com Emoções

Aplicação que analisa o sentimento de um texto, identifica sua polaridade como **positiva, negativa ou neutra** e gera automaticamente um arquivo de áudio.

### Funcionalidades

* Análise de sentimentos
* Identificação da polaridade do texto
* Conversão de texto em voz
* Geração automática de áudio
* Gráfico de polaridade
* Interface gráfica com Tkinter

### Tecnologias

* Python
* TextBlob
* Pyttsx3
* Matplotlib
* Tkinter

**Arquivo:** `conversor_emocoes.py`

---

## 📚 Sistema de Busca de Livros

Aplicação que utiliza a **Google Books API** para pesquisar livros por título ou autor e apresentar os resultados de forma organizada.

### Funcionalidades

* Busca por título ou autor
* Exibição dos livros encontrados
* Identificação de autores, gêneros e anos de publicação
* Filtro dos 10 livros mais antigos
* Gráfico de gêneros
* Gráfico de anos de publicação
* Interface gráfica com Tkinter

### Tecnologias

* Python
* Google Books API
* Requests
* Pandas
* Matplotlib
* Tkinter

**Arquivo:** `busca_livros.py`

---

## 🏀 Estatísticas Esportivas

Aplicação desenvolvida para consultar estatísticas de jogadores da NBA utilizando uma API esportiva, permitindo analisar médias de desempenho e visualizar os resultados em gráficos.

### Funcionalidades

* Busca de jogadores
* Consulta de estatísticas
* Cálculo de médias
* Análise de pontos, assistências e rebotes
* Rankings
* Gráficos comparativos
* Interface gráfica com Tkinter

### Tecnologias

* Python
* balldontlie API
* Requests
* Pandas
* Matplotlib
* Tkinter

**Arquivo:** `estatisticas_esportivas.py`

## 🚀 Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
```

### 2. Instale as dependências

```bash
pip install requests pandas matplotlib textblob pyttsx3
```

### 3. Execute o projeto desejado

```bash
python conversor_emocoes.py
```

```bash
python busca_livros.py
```

```bash
python estatisticas_esportivas.py
```

> **Observação:** o projeto de estatísticas esportivas pode exigir uma API Key da balldontlie.
